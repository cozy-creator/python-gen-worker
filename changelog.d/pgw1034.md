  could not fail, wire fields the child never read, and receipt claims nothing
  verified.** `SEAL_VERSION` 1 -> 2, so every seal-v1 cell is re-minted once per
  (family, lane, sm); that is the whole re-key cost and it buys the removal of
  the last operator-settable recall salt. Deleted: the `code_closure` envelope
  block (`aot_mint.shared_identity_blocks`) and `ExportSpec.closure_roots` —
  pgw#990 took source content out of the key, and the memo it was demoted to is
  `compile_cache`'s own block, read from ITS copy; nothing read this one, which
  cost a per-mint AST walk of the import closure plus declare-size pressure
  (th#1645 class). `aot_package.strict_mode_drift` — it compared
  `meta["strict_export"]` against the value assigned to it thirteen lines
  earlier and could not fail; trace mode is bound where it CAN be wrong, in
  `aot_serve.verify_contract`, which recomputes each entry's `class_hash` with
  the mode the foreign bytes record and refuses by name. `CompileCellSpec`'s
  `regional`/`text_len`/`dynamic` and `DynamicDimSpec` with them, plus
  `mint_child.compile_cfg` — the struct's stated justification (child key
  parity) has been stale since pgw#758: the child computes no key, and
  re-inflating a `registry.CompileCell` only manufactured one whose contract

  struct directly. The `env_seal` `epoch` axis (`COZY_CELL_EPOCH`) — no producer

  runtime-key axis — gw#577 took it out of every key and gate; the residue was a
  fact nothing read bought with a `libcuda` dlopen and `cuInit(0)` on every
  `runtime_key()` call, and `verify()` calls it per artifact. Six `Receipt`

  `artifact_path`, `manifest_digest`, `fingerprint_digest`, `issued_at_unix`);
  the signature still covers the whole payload, so an undecoded claim is inert
  rather than trusted. `issued_at_unix` in particular had no freshness check and
  could not honestly acquire one — a fixed-duration condemn is what the
  no-magic-timeouts rule forbids, and receipt currency is the revocation list.
  The multi-algorithm digest ceremony collapsed to the one algorithm that

  list-valued `artifact_digest` query param -> a scalar. The TAG stays on the
  wire; only the pre-paid plurality is gone. **Audited and KEPT, deliberately:**
  the `python_hash_seed`/`hash_randomization` seal facts (the audit called them
  constants — `SCRUB_PREFIXES` does not cover `PYTHON`, so an operator CAN set a

  list with two copies; they are deliberately different axis sets for two
