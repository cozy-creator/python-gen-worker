### Boot-time cell-key derivation, and pull-by-key adoption (pgw#1089 / pgw#1090, DESIGN-RULINGS §4.27/§4.29)

- **A worker now derives its `ck1` cell key AT BOOT, from code alone**, before a
  weight is resident in the process: the compile target is composed
  structure-only (pgw#1080's builder, widened to the boot path as that issue
  owed), each declared graph class is traced with fake tensors in its own OS
  process, and the per-class hashes are folded with a fresh
  envelope/sm/toolchain. New: `gen_worker.boot_key`,
  `gen_worker.boot_trace_child`, `aot_mint.trace_for_key`.
- **`entry_graph_block` is v3 and program-only.** v2 read `constant_fqns` and
  `fused_constants` off the COMPILED PACKAGE, which made identity unstatable
  before a compile — and, already live, made a weightless mint key differently
  from a real-weight mint of the byte-identical graph (pgw#1080's mandatory
  `use_runtime_constant_folding` moves both package-side sets). Both facts are
  a function of graph × toolchain × sm, so they carry no bits the key lacks;
  they stay PROVEN at mint (`program_package_drift`, `eliminated_constants`)
  and are no longer KEYED. **This re-keys the cell corpus.** The `ck1` counter
  deliberately does not move (pgw#1059 amendment 1 / §1.27(g)).
- **`POST /v1/worker/cells/resolve` has a worker client** (`gen_worker.cell_resolve`,
  pairing with tensorhub th#1750): a derived key is answered with ONE entitled
  artifact or a MISS. A hit becomes an ordinary `aot_cell` arm order, so it runs
  the Plan path's admission gates unchanged — never a second admission brain.
  A cold pod can therefore adopt with zero dispatches having occurred, which
  the hub's other resolver (which only verifies what a worker already armed)
  structurally could not allow.
- The boot key is memoized as **per-class graph hashes only, never the folded
  key** — the other three axes re-derive every boot in milliseconds and must.
  A memo is checked against the freshly traced hashes whenever this pod mints;
  a disagreement invalidates it and re-traces, so a memo can cost a re-trace
  and can never produce a wrong key.
