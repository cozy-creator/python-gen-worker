- Typing: `mypy` now runs **strict by default** over `src/gen_worker`. A module
  added from here on is born strict; the 101 modules that were not clean at
  adoption carry a named, single-flag exemption in `pyproject.toml`. Measured at
  adoption: 413 `--strict` errors in 101 of 266 modules, so 165 modules were
  already strict-clean and are now locked there. `check_untyped_defs`,
  `disallow_incomplete_defs`, `strict_equality`, `extra_checks` and
  `disallow_subclassing_any` cost zero errors and are simply on — which means
  the `gen_worker.convert.*` untyped function bodies, previously unchecked
  entirely, are checked now.
- New CI guard `scripts/lint_mypy_ratchet.py` (`fast gates`): the per-module
  exemption lists may shrink but never grow, `strict = true` may not disappear,
  and a new kind of opt-out must be recorded before it can be used.
- Typing: the **test tree is type-checked**. Until now `mypy tests` did not
  produce a report — it refused to start ("Duplicate module named `conftest`"),
  so all 486 test modules had zero static coverage, which is where the doubles
  that lied about production contracts lived. `explicit_package_bases` plus
  `mypy_path = "src"` unblocks it; no `__init__.py` files were added, so
  pytest's import mode is unchanged. Measured once checkable: 2,016 errors in
  316 of 486 modules at the test posture, so **170 test modules were already
  clean and are checked from this commit on** — and a test file added tomorrow
  is born checked.
- Test code is exempt from the five annotation-completeness flags (a test may be
  `def test_x():`). Everything that catches a double contradicting production
  stays on: `arg-type`, `attr-defined`, `return-value`, `call-arg`, `override`.
- `scripts/lint_mypy_ratchet.py` now also refuses an undeclared wildcard
  exemption, and asserts CI actually hands mypy the paths the config covers —
  dropping `tests tests_v2` from the invocation would restore zero coverage
  with every check still green.
- Typing: the endpoint-**authoring** surface (`gen_worker.api.*`,
  `gen_worker.testing`) is free of bare generics and locked at
  `disallow_any_generics`. 30 sites: `Slot` → `Slot[Any]`, `RequestContext` →
  `RequestContext[Any]`, bare `dict`/`set`/`tuple` → parameterized. These are
  the types an endpoint author's editor resolves, so an unparameterized one
  silently erased their argument types at the seam they touch most. The
  burn-down list drops 69 → 62 modules.
- Typing/layering: `no_implicit_reexport` closed for `request_context`. Six
  call sites now import `_decode_unverified_jwt_claims` from
  `request_context._helpers`, the module that OWNS it, instead of through the
  package `__init__` — three other modules already did exactly this, so the fix
  converges on the form the newer call sites use. Burn-down 17 → 16.
  Two candidates were investigated and deliberately NOT taken: `chunk_upload`
  (the indirection is the seam a publish test monkeypatches — 13 failures,
  measured) and `cuda_root` (closing it strands a callable in the pgw#849
  baseline). Both reasons are recorded beside their exemptions.
- Fixed two unguarded `Optional` dereferences in
  `tests/test_device_peak_bank_pgw1205.py`. They reached `master` because CI
  runs only on `pull_request`: pgw#1205 and pgw#1202 PR 3 were each green
  against a base that lacked the other, and nothing re-checked the merge.
- Typing: `Slot[Any]`/`RequestContext[Any]` audited one signature at a time
  against a single rule — **a type variable that appears exactly once in a
  signature is identical to `Any`**, so it is worth writing only where `D`
  binds two or more positions. 11 sites converted, 14 kept with a stated
  reason. The one that matters: `resolve_slot` took `Slot[D]` *and*
  `Type[D]` and returned `ResolvedSlot[Any]`, throwing the type away at the
  point it was known; it now returns `ResolvedSlot[D]`, so an endpoint author
  reading `ctx.slots[...].defaults` gets their own defaults class instead of
  `Any`. Verified by A/B: with the TypeVar a wrong annotation is an error;
  with `Any` the same code reports `Success`.
- Typing: `request_context` (the `ctx` every handler is handed) is locked at
  `disallow_any_generics` and `warn_return_any`. `ctx.models`/`ctx.loras` are
  typed because the shape-preserving deep copy behind them says so once at its
  definition instead of leaking `Any` to every caller; `ctx.save_image/audio/
  video` return their real asset classes via a generic `_as_asset`; `ctx.slots`
  is `Mapping[str, ResolvedSlot[Any]]`, which is what its docstring always
  claimed; and `ConversionContext`/`DatasetContext`/`TrainingContext` name the
  defaults type they resolve instead of subclassing a bare generic. Burn-down
  62 → 60 and 26 → 25.
- Typing: the BUILD-TIME surface (`registry`, `discovery.discover`,
