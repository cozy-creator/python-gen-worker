- **BREAKING — the v1 SDK is DELETED. `Model[T]` + `@entrypoint` is the only author surface.**
  Paul's hardcut ruling: *"you should hardcut the old SDK system everywhere. no legacy support, no
  supporting both. It's fine if everything breaks in the interim. Hardcut."* 187,401 lines removed
  across 502 files.

  Gone from `gen_worker`: `endpoint`, `job`, `Slot`, `ResolvedSlot`, `resolve_slot`, `ConfigParam`,
  `variant_of`, `worker_function`, `Compile`, `CompileAxis`, `AxisClass`, `DynamicDim`, `NoWarmup`,
  `AcceptsReferences`, `RuntimeFormula`, `OBJECTIVES`, `ObjectiveMismatchError`, the
  `GraphClass`/`Dim`/`Fork`/`Input`/`Arg`/`MintBlocker` export-declaration vocabulary, the
  `api.derive` assertions, the `api.streaming` signals, and the `StringEnum` alias — payload enums
  import stdlib `enum.StrEnum` directly.

  Gone from the package: `model/**` (the 26-family catalog, `ModelSpec`/`GraphModelSpec`, codegen,
  solvers, tuned, bind, inject, residency), `registry.py`, `warmup.py`, `executor.py`,
  `lifecycle.py`, `serve/**`, `keyset/**`, `aot_*`, `mint_*`, `boot_adopt`/`boot_key`/
  `boot_trace_child`, `fleet_compiled_graphs`, `local_serve`, `serving_mode`, `numerics_probe`,
  `runtimes/**`, and the `gen-worker` subcommands `run`, `serve`, `invoke`, `prefetch`, `families`,
  `model`, `job`. Local serving is `python -m gen_worker.serving`.

  **A deleted name refuses BY NAME.** `gen_worker.endpoint` raises
  `V1SdkDeleted(ImportError)`: *"gen_worker.endpoint was deleted: v1 SDK deleted, migrate to
  Model/@entrypoint, see se#757. Use @entrypoint on a module-level function."* A user module still
  carrying a v1 decorator stamp raises the same type at BOOT, so an unmigrated endpoint fails with
  a migration pointer instead of an empty surface.

- **The manifest declares ONE block.** `python -m gen_worker.discovery` emits `entrypoints[]`
  alone — no `functions[]`, no `jobs[]`, and no empty predecessor beside the successor. The hub
  already folds `entrypoints[]` at its one decode (`builder.ParseManifest`), so a v2-only manifest
  needed no hub change to admit. `manifest_blocks.DECLARATION_BLOCKS` is DELETED rather than
  extended: a name for "the set of blocks" is a second home for the vocabulary, and that second
  home is what went stale twice — `functions`-only walks went blind on jobs-only images (pgw#1354)
  and again on entrypoints-only images (pgw#1395). One block, one reader, nothing to sync.

- **The worker boots on the v2 surface.** `worker.py` is rewritten as the connector from the hub
  gRPC transport to `gen_worker.serving`: harvest `@entrypoint` declarations from the manifest's
  modules, build a `ServeLoop` with residency leases, route `RunJob` → signature-derived envelope →
  `spec.fn` → `JobResult`. Before this, `@entrypoint` stamped `__cozy_entrypoint__` while
  `registry.extract_specs` read only `__gen_worker_endpoint__`, so a v2-only release published
  green and then died on `Worker.__init__` with *"no @endpoint classes and no @job functions
  found"*. `transport.py` is unchanged.

- **`gen_worker.worker_main` is renamed back to `gen_worker.entrypoint`, and the module name is a
  WIRE CONTRACT (th#2168).** Every hub-synthesized Dockerfile writes
  `ENTRYPOINT ["python3", "-m", "gen_worker.entrypoint"]` and the publish gate refuses an image
  whose entrypoint does not run it, so the rename had been killing every image built from a live
  endpoint pin at container start — before any refusal class could speak. `build_guarantees.py`
  now encodes the requirement, so a future rename fails a guarantee instead of a container.

- **The A19 slot-layout gate is deleted, and it was firing falsely by construction.**
  `discovery/validation.py` demanded `Slot(layouts=...)` on every model slot; pgw#1394 established
  that a serving LANE is not an artifact-layout handle and removed `layouts` from v2 entrypoint
  slots entirely. Pointed at `entrypoints[]` the gate refuses every v2 endpoint, adapter slots
  included. It only ever passed because it walked a `functions[]` that was empty for a v2 release.
  The lane is gated on the release-derive document instead (th#2160), and the hub's matching
  A20(c) census skips a v2 manifest for the same reason (pgw#1398 / th#1468).
