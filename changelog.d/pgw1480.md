- **A phase-vocabulary member that nothing references cannot fire, and 18 of `EagerPhase`'s 23 were
  in that state.** `phase` is a typed wire column, so a phase enum is an INSTRUMENT — an operator
  counts by it and a proof condition is written against it. se#780 wrote its headline pass condition
  as *"`boot_ended_uncompiled` must be ABSENT"* and called it "the one that makes this a proof
  rather than a story". It was absent **unconditionally**, and an 80 GB rental was about to be
  judged on it.

- **The filing named one member; the measurement found the whole panel.** At `2af52988`, 18 of 23
  members are referenced nowhere outside their own definition, and **not one** of the 183 `phase=`
  emit sites in `src/gen_worker` feeds from a phase enum symbolically. The enum was created
  (pgw#824, pgw#1035) precisely to close a two-lists-of-literals drift channel; the v2 hardcut
  deleted its emitters and left the vocabulary standing.

- **`scripts/lint_phase_enum_emitters.py` kills the CLASS rather than the instance**, in the repo's
  own census idiom (`config_reads_allowlist.txt`). Three properties, each proven red against a real
  tree: a NEW unreferenced member is red so the class cannot grow; a censused member that GAINS a
  reference is red so the census must shrink and can never become a graveyard; a censused member
  that no longer exists is red so no row outlives its member. In `fast gates` + `task lint`.

- **What it checks is stated honestly: referenced-in-code, not "emitted".** An emit site can be
  reached through a variable or a helper, so an AST-precise emit check would report false violations
  and get switched off. The weaker property is still decisive, because a member nothing references
  cannot be emitted by anything.

- **The enum's own docstring was making a false claim** — it promised `POSTURE_*` aliases in
  `serving_mode`, a module the hardcut deleted; the only `POSTURE_*` constants in the tree are
  `receipts.py`'s unrelated `armed`/`local`/`unset`. Corrected to say what is measurably true.

- **WIRE-OR-DELETE per member is deliberately NOT done here.** The hub groups historical
  `worker_activity_events` by these values, so retiring 18 of them is a wire decision and a ruling,
  not something a serving-lane fix takes unilaterally at 06:00. The census is the burn-down list and
  the gate guarantees it shrinks.

- ⚠️ **The gate's own prose arm caught a bug in the gate** before it landed: the symbolic check
  scanned raw text, so a comment EXPLAINING a dead member made it read as alive — the failure
  direction that matters, since it marks a dead instrument live. Both checks now run over code lines
  only.
