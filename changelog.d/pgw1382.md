# pgw#1382 — the Model/Endpoint split lands (SDK core)

The author surface splits along state. `gen_worker.Model[MT]` is the
stateful class: model type via the generic parameter, weight-format lanes
via the `lanes=` class-header kwarg, `load(ctx)`/`unload(ctx)` no-op-default
hooks (unload = drain-then-call, best-effort-never-correctness, cannot pin
residency), request-scoped deviations only through model-owned restoring
scopes. `@gen_worker.entrypoint` marks stateless module-level functions —
ctx-first signature `(ctx, payload, model, turbo: Adapter | None,
loras: list[Adapter])`; parameter annotations ARE the model/adapter slot
declarations (param name = slot name), statically extractable without
executing author code beyond import; malformed signatures are typed
refusals at import.

The ctx splits with the state: `LoadContext[MT]` (checkpoint_dir/ref, lane,
`load()`/`compile()`/`defaults()` seams — pgw#1380 engine, tcg#42
AdoptSession, pgw#1377 typed decode) rides load/unload; `RequestContext`
(request facts `is_trace`/`checkpoint_ref` + the salvaged base surface +
`step_callback`) rides entrypoints and is now THE root `RequestContext`.
`Adapter` (name/path/defaults/scale) and `ImageFormat` (save_image's value
vocabulary) export at top level. `gen_worker.models` gains the pgw#1377
seam: `ModelType`, `Knob.resolve`, `SDXL` (+ `SDXL.Lora`).

Deleted: the `Endpoint` base class, `ServeContext`, `EndpointDeclaration`/
`ENDPOINT_ATTR` and the setup/teardown hook shape (pgw#1372's landing,
re-plumbed clause-for-clause). The worker main module renames
`gen_worker.entrypoint` -> `gen_worker.worker_main` — the `entrypoint` name
now belongs to the decorator (Dockerfiles: `python -m gen_worker.worker_main`).
`EndpointHost` boots one instance per referenced Model class and serves
under SINGLE-FLIGHT per instance (admissions in slot-name order for
multi-model entrypoints); eviction drains, then calls `unload`, logs
failures, proceeds.
