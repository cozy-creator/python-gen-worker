### Changed

- **The `#` fragment is a COMPILE CELL KEY and nothing else** (pgw#1290 / th#2031,
  completing DESIGN-RULINGS §1.32(d)). `parse_model_ref` now raises
  `RefFragmentRemoved` for a fragment on any repo that is not `root/family-<f>`.
  It used to PARSE and then be dropped — the hub's resolve body has carried no
  flavor field since th#1803 — so `owner/repo@prod#fp8` quietly resolved to
  whatever the release's default variant was and reported success. Narrow a
  release with the `?<lane-spec>` tail instead.
- **Renamed, not aliased:** `refs.FlavorSelectorRemoved` -> `refs.RefFragmentRemoved`,
  `refs.refuse_flavor_selector()` -> `refs.refuse_ref_fragment()`,
  `TensorhubRef.flavor` -> `TensorhubRef.fragment`.
- **`ref_grammar_vectors.json` re-keyed** (digest bumped): the `flavor` field is
  `fragment`, the eight non-cell `#` vectors became REFUSAL vectors, and four
  new vectors pin the cell/non-cell boundary (`root/family-sdxl@prod#…` parses;
  `root/family#…`, `root/sdxl#…` and `notroot/family-sdxl#…` refuse). Tensorhub
  vendors the same bytes.
