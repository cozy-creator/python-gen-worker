- **BREAKING (pgw#1206 A1) — `hubio/` extraction.** The worker-wide CAS write
  client moves out of `convert/`: `gen_worker.convert.hub` →
  `gen_worker.hubio.client`, `gen_worker.convert.publish_journal` →
  `gen_worker.hubio.journal`. Verbatim moves; no behavior change. Phase B folds
  the remaining upload transports into `hubio/`.
- **BREAKING — naming pass (the lane/ladder RFC).** "Execution lane" now means
  exactly one thing (the §1.33 tensor-layout serving lane):
  `gen_worker.models.execution_lane_gate` → `gen_worker.models.lane_residency_gate`
  (`ExecutionLaneGate` → `LaneResidencyGate`, `arm_execution_lane_gate` →
  `arm_lane_residency_gate`) — it is a VRAM LRU residency gate, not a lane.
  `gen_worker.intent_registry` → `gen_worker.lifecycle_intents` (it is the
  th#1085 lifecycle-intent projection, not a discovery registry).
  `gen_worker.cli.transport` → `gen_worker.cli.sockaddr` (kills the collision
  with the root gRPC `transport.py`).
- **BREAKING — one public facade.** `gen_worker` (the documented root import) is
  now the single facade and absorbs the ten previously api-only names
  (`AuthError`, `Binding`, `MediaAsset`, `OutputTooLargeError`,
  `RefCompatibilitySurprise`, `ResourceError`, `SnapshotBuildFailedError`,
  `Tensors`, `WorkerError`, `resolve_slot`); `gen_worker.api` no longer
  re-exports anything. Deep module imports (`gen_worker.api.types`, …) are
  unchanged. Known consumer repins to update: `from gen_worker.api import
  PromptRole` (minimax-h3) → `from gen_worker import PromptRole`;
  `gen_worker.convert.hub` imports in training-endpoints →
  `gen_worker.hubio.client`.
- **A2 — One Rung ladder.** The degrade-don't-OOM machinery's three
  vocabularies (plan-time `serve_fit.RUN_*`, placement modes, bare load-rung
  strings) now project from ONE ordered ladder, `models/rung.py`
  (`descend()`/`price()`/`floor_of()`/`touches_host_ram()`). serve_fit's three
  runtime re-constructors (`demoted`/`load_rung_engaged`/`cast_dropped`)
  collapse into one `replan()`; the executor's three bookkeepers into one
  `_record_rung_transition()`; `memory.degraded_log_line` moves to
  `rung.transition_line`. The ruling is now ONE red-verified test
  (`tests/test_rung_ladder_pgw1206.py`).
- **Fix (wire): `FnDegraded.ran` stays inside the hub's exact-match RunMode
  vocabulary.** `demoted()` used to send `ran="offload:<placement>"`, which
  tensorhub's `degradation_reschedule.go` exact-match switch never recognizes —
  runtime demotions silently missed the VRAM-driven-drain arm. Placement detail
  now travels in `reason`; the lifecycle re-emit dedupe keys on (ran, warning)
  so deeper same-mode demotions still re-report.
- **B — One transport.** The credentialed upload lane is DELETED whole:
  `s3_transfer.py` and `presigned_upload`'s `transfer_grant` branch had ZERO
  hub producers (tensorhub never emits `transfer_grant`), and **boto3/botocore
  leave the dependency set** — the worker never holds store credentials; a
  grant is a presigned URL with the digest signed in. The urllib3 PUT engine
  moves to `hubio/transport.py`; presigned PUT status classification is ONE
  table (`put_verdict`: 403-past-expiry ⇒ re-plan, 408/429/5xx transient)
  projected by both the engine and chunk-CAS.
- **One grant-expiry behavior**: an expired presign is a RE-PLAN, never
  terminal. chunk-CAS already re-planned (pgw#1004); the media multipart path
  now re-creates its upload session once on a 403'd part PUT and re-drives —
  only a 403 on the fresh presigns stays terminal.
- **`hubio/fetch.py` — `fetch_verified()`/`afetch_verified()`**: THE verified
  single-object download (writer-unique `.part` staging, Range resume,
  in-loop byte cap raising `StreamTooLarge`, tag-dispatched digest verify,
  durable atomic finalize, progress-floor retry). `models/cozy_cas`'s
  downloader pair and `_datasets`' bespoke shard streamer die into it
  (datasets keep loser-cleans-up semantics via `resume=False`). Deliberate
  non-duplicates stay: chunk-CAS positional engine, the SSRF-guarded
  input-asset fetch, hf_hub's branch.
