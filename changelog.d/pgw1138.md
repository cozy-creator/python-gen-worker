- **pgw#1138 follow-through: the `X-Cozy-Owner` header is gone from the SDK,
  and so is the state that existed only to send it.** pgw#1138 removed the
  header from the media-upload client, which is what th#1799 needed, and
  recorded the two remaining senders — `convert/hub.py`'s repo `_headers()` and
  `publish_dataset_revision`'s dataset headers — as out of scope. Nothing in
  tensorhub reads `X-Cozy-Owner` in any version (the only near-match is the
  orchestrator-internal `X-Cozy-Owner-Forwarded`), so both sends are deleted.
  With them goes `HubClient(owner=...)`: the field's only reader was the header,
  which is why `fleet_cells.py` was passing the literal `owner="root"` to
  satisfy a required argument that named nothing. The repo and dataset ROUTES
  keep their org segment — there the org is part of the resource's identity,
  which is exactly the line th#1722 §C drew.
