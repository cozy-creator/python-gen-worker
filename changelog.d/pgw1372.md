  Authors ship code as-is: `endpoint.toml`'s `main =` module carries one endpoint
  class; the worker loads it, calls `setup(ctx)`, and routes requests to handlers
  by function name — no catalog, no ModelSpec, no codegen. `ServeContext` is the
  `main_v2.py` surface (`ctx.checkpoint_dir` — the lane-contract-converted
  checkpoint tree, `ctx.lane`, `ctx.checkpoint_defaults(T)`, `ctx.adapter`,
  `ctx.is_trace`, `ctx.step_callback`) on top of the existing RequestContext.
  `python -m gen_worker.serving` boots an endpoint locally with zero hub.
