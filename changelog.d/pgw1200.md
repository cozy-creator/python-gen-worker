- **pgw#1200 (§4.35): the FX-cache failure report stops claiming a discrimination it cannot make.** `fx_cache_failure_report` classified a failed dynamo warmup proof into three named classes — `fresh_keys>0` = the boot computed DIFFERENT keys from the cell (B1), `fresh_keys=0` with same-key re-saves = the keys MATCHED and the miss is in torch's candidate-load path (B2), `cell_keys=0` = the artifact was unreadable. **All three are differences measured against a CELL side read out of a `torch-inductor-cache` tarball's `inductor/fxgraph/` tree**, and pgw#1178 deleted that format's last writer while pgw#1181 deleted the format. With an empty cell side the arithmetic does not degrade, it **inverts**: `fresh = live_keys − seeded` becomes EVERY live key, so **B1 was named on every boot with any FX entry at all**, B2 became structurally unreportable, and `cell_keys=0` — the "unreadable artifact" class — became the normal case. Measured on the real function: handed an exported cell, exactly what the caller passes today, the output was **byte-identical to passing `None`**, which is the shortest proof the argument carried no information.
- **The disposition is §4.35's, and the amendment picks it.** This is a gate enumerated by **reachability of the gated branch**, not by a config scan — the `if artifact is not None:` branch is *reachable*, its yield is not. ON is impossible (there is no format to read), FINISH would mean resurrecting the format, so the cell half is **DELETED**. What survives is what the dynamo lane can honestly observe about itself and is reported as a census rather than a verdict: the live FX key count, the missing-cache-directory case, and this process's extern-libs key. The two executor call sites keep their `proves_inductor` scoping (pgw#722 finding 2) and lose only the argument they could not supply. `fx_key_forensics`, `_fx_entry_lines` and `_fx_components` go with their only caller — pgw#1178 had kept all three alive by anchoring them here, which is the reachability trap itself.
- **A diagnostic that always names one class is worse than none, because it is read as evidence** — the same defect class as a green fence guarding nothing, and §1.22's rule that absent evidence is a verdict, never a silent pass.
