- **pgw#1638: `ctx.load` runs the config's quantizer over the meta skeleton, so fp8-blockwise checkpoints load again.** The skeleton was built with the bare `cls(config)`, and `HfQuantizer.preprocess_model` — the step that swaps `nn.Linear` → `FP8Linear` and registers `weight_scale_inv` — lives only inside `from_pretrained`. So a component whose config declares a quantization came up as plain linears with no home for a single scale tensor: `minimax-h3` 0.12.8 died on an H200, three identical attempts, `357 tensor(s) name nothing in component 'text_encoder'` — 51 layers × 7 quantized linears, every orphan a `weight_scale_inv`, against a checkpoint that was correct. Same family as pgw#1626 (`tie_weights()`, also skipped, also paid for on a pod), so the preparation `from_pretrained` runs is now written out in `skeleton.py` in its order — construct, cast to the lane, swap the modules the config's quantizer declares under `init_empty_weights` — with the trailing `postprocess_model` as `skeleton.finish_quantized()` after the stream. The declared rule is cross-checked against the image's decode set (`require_decodable`) before anything is swapped, a quantization method that names no quant rule is refused by name, and a diffusers component declaring one is refused rather than silently mis-built.
- **The lane cast no longer rounds a quant rule's scale grid.** `hf.fp8-blockwise@1` stores an F32 `[out/128, in/128]` grid beside each fp8 weight, and H3's declared lane is its DiT's — bf16. The pgw#1623 cast saw 357 off-lane wide floats and would have cast them all, after which `_assert_lane_dtype` passes: plausible numbers, wrong ones, green. Tensors a quantizer owns are now out of both the cast's and the assertion's scope, which is what `engine.py`'s property 3 already claimed and only the fp8 weights (not wide floats) happened to satisfy.
- **pgw#1633's skeleton-conformance suite gains a quantized arm.** The real `minimax-h3` conditioner config is vendored config-only; the meta build must produce `FP8Linear` and exactly 357 `weight_scale_inv`, a checkpoint-shaped fill must leave nothing on meta, and the red arm neuters the quantizer step and asserts the orphans are exactly the 357-pattern. CPU-only, no weights, no GPU — this wall is now caught offline for free.
