- **pgw#1204: `test_stream_bounds_pgw1013::_aborted_early` asserted an ORDERING with a BYTE-COUNT
  THRESHOLD, so it converted CI scheduling into a boolean — and billed five cuts.** The property is
  ordinal: *did the size check run inside the download loop or after it?* It was being checked as
  `bytes the server got onto the wire < 8 MiB` against a 32 MiB body — a quantity nothing in the
  code under test controls, decided by the runner's scheduler and by kernel socket buffers on both
  ends. `completed.md` records it flaking four separate times (once at 8,650,752 bytes); the
  0.113.2 cut made five, at 8,716,288, and cost a 16-minute rerun. Every time, the same tree was
  green on rerun — and on the 0.113.2 cut the same tree was green on `workflow_dispatch` while red
  on `pull_request`, which is what established it as a flake rather than a red.
- **The server can answer the ordering question exactly, and now does.** If the client aborts
  mid-transfer the write loop dies on a broken pipe and never reaches its last byte; if the check
  ran after the loop the client read all 32 MiB and the server completed. The rig records that
  (`finished`, sticky in the direction that makes the assertion fire rather than hide) and
  `_aborted_early` asserts on it. `ABORT_SLACK` is deleted — there is no threshold left to tune.
  The byte count survives in the failure MESSAGE, where a number belongs.
- **Measured, not asserted: over 25 identical runs on an IDLE box**, the old predicate's input
  ranged **0.00 – 7.06 MiB with stdev 1.92 MiB** against its 8.00 MiB line — peaking within half a
  standard deviation of the threshold with no CI load at all. The new predicate's input was `False`
  in **25/25**. That is the difference between sampling a random variable and sampling an invariant.
- **Severance, both directions, because rewriting a guard is exactly when it goes vacuous.** One row
  reproduces pgw#1013's actual defect (read the whole body, then compare sizes) against the same rig
  and proves `_aborted_early` **fails** on it; another drives the shipping bounded copy and proves it
  **passes** — so a green row means "the bound held", not "the predicate cannot fire".
