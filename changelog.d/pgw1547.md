pgw#1547: the retired word "cell" now has a FENCE (Paul, 2026-08-20: *"we
stopped using the term 'cell' a while ago. They are now 'graphs' and 'graph
specializations'."*). pgw#1363 retired the word two days earlier and it did not
stick, because nothing watched it: `_PROVEN_CELLS`/`_QUARANTINED_CELLS` were
still `compile_cache` globals, `tests/conftest.py` cleared the quarantine ledger
through a `getattr(_cc, "_QUARANTINED_CELLS", set())` that would have gone
SILENTLY no-op the moment the name moved, eight mint fixtures still called a
compiled graph a cell, and `private_deployment_leg.py` still spelled its client
method `admin_cells` for a route the hub already serves as
`/v1/admin/compiled-graphs`. All of that is renamed; the conftest ledger clear is
now a direct attribute access that cannot silently stop clearing.

`scripts/lint_retired_cell_spellings.py` is a new `fast gates` step. It matches
`cell` NOT PRECEDED BY A LETTER, which excludes the 84 live
`cancelled`/`CancelledError`/`cancellation` uses structurally rather than by an
allowlist, and its selftest pins that arm so an over-reaching pattern is a
lint bug rather than a source edit.

The hub-owned wire spellings and the on-disk triple are still deferred, exactly
as pgw#1363 left them — but they are now ENUMERATED rather than merely
unmentioned: all 83 carry a `# cell-spelling: <reason>` proof at the line naming
the contract that pins them (proto fields under `PROTO_DIGEST`, the
`jit_cell`/`aot_cell` serving modes, the `cell_*` boot phases, the `cell_read_*`
claims, and `GEN_WORKER_LOCAL_CELLS_DIR` + `aot-cells/` + `cell.tar.gz` under the
pgw#1237/cl#56/th#1914 runtime-env parity contract that cozy-local's `paths.go`
and tensorhub's `localcompiledgraphs` both bind). That set can now only shrink,
and a bare marker with no reason is not a proof.
