- The retired library names are gone from this tree. The CAS/transfer library is `tensorfs`
  and the compiled-graph library is `torchcg`, upstream and here: the vendored package
  directory is now `src/gen_worker/_vendor/torchcg`, every import says
  `gen_worker._vendor.torchcg`, and the prose that pointed at modules nobody can import
  points at the real ones. No dependency and no lock entry changes — both packages have been
  vendored since pgw#1310 and stay vendored, because a published `gen-worker` wheel whose
  `Requires-Dist` named either project would be unresolvable for every consumer (both PyPI
  projects are permanently deleted, and PyPI refuses a direct reference at upload).
- `scripts/lint_retired_package_names.py` gates it in `fast gates`. Text-based rather than
  AST-based, unlike the vocabulary fence beside it: here a docstring naming a dead module IS
  the defect. Case-insensitive, which is what makes it new — every earlier sweep of this
  rename used a case-sensitive grep and left the prose spelling untouched, 5 survivors
  visible where there were really 48.
- The rename moved no key. `boot_key._tcg_version()` folds the vendored REV into the compile
  memo, not the package name, so every cached compiled graph on the fleet still hits;
  `tests/test_retired_names_pgw1297.py` pins the pre-rename value so a future edit that folds
  the name instead goes red before it re-mints the fleet.
