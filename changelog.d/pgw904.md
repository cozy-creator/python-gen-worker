### Changed

- **pgw#904: the exact-artifact cutover — the worker stops resolving and
  starts obeying.** `SchedulerMessage.run_attempt` is now handled: the Plan
  head (`executor.handle_run_attempt`) builds the immutable Plan
  (`PlanFactory`), admits it through the `PlanLedger` (an identical replay
  re-acks without re-executing; a re-dispatch of one attempt under a
  DIFFERENT spec digest fails the attempt closed with one INVALID result
  naming both digests), joins the grant's digest-keyed transport to the
  digests the spec pinned, materializes the ONE artifact `Arm.artifact`
  names (`aot_delivery`, content-digest-verified), and drives the shared
  dispatch driver. The consumer is complete but unreachable in production
  until tensorhub's fenced producer cuts over (th#1457).
- **The dispatch driver is neutral (part b).** Every shared frame —
  `_run_job_grouped`/`_run_job_pinned`/`_execute`, adapters, admission
  leases, config, output serialization — now reads a head-produced
  `_JobOrder`, never `pb.RunJob`. The only frames that still read the wire
  message are `handle_run_job` and its `_legacy_order` projection, which die
  whole with `RunJob` at th#1457's cut. There is no translator in either
  direction: neither a Plan built from `RunJob` nor a `RunJob` built from a
  Plan.
- **The second resolver is deleted (part c, 874-line replacement-gated
  set).** `aot_cells.py` (catalog fetch-and-filter discovery) is gone whole;
  so are `fleet_cells`' discovery branch, the dark `_fetch_compile_snapshot`
  snapshot scan, the coarse-family lane ladder
  (`_execution_lane_effective_spec` — a `RunJob.lane` instruction the
  endpoint does not itself serve now refuses typed), and
  `_slot_dispatch_binding`'s silent fallback (non-CAS dispatched refs now
  refuse instead of falling back to the declared default; the gw#583
  fixed-slot identity gate stays). A fake catalog — or the same rows
  reordered — cannot affect delivery because nothing lists a catalog any
  more.
- **The ordered arm obeys exactly (`fleet_cells.arm_ordered`).** `aot_cell`
  arms the named artifact through a STRICT receipt gate (a refused receipt
  is a typed refusal, never a drop-to-eager), the §4.26 exact-publisher
  check (`Receipt.publisher_org_id` must equal the org the spec named), and
  pgw#903's declared-identity verification (`expected_from_plan` is off the
  IN FLIGHT unreached baseline). `dynamo` arms JIT intake; `eager_only`
  arms nothing. No discovery, no ranking, no self-mint fallback — a failed
  ordered arm is typed and terminal for the attempt.

### Removed

- **The wall deadline (part d).** `RunJob.timeout_ms` is no longer read,
  `EndpointSpec.timeout_ms` and `ctx.deadline` are deleted, and `_execute`
  aborts only on the registry's own `progress.self_diagnosis()` confession
  (typed RETRYABLE naming the stalled counter, its age and its window).
  Kill/condemn authority is liveness + progress-staleness, never a fixed
  duration — a slow-but-advancing handler now COMPLETES where the old wall
  bound killed it.
