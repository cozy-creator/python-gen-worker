- **ie#681: `streaming_w8a8_snapshot` forwards `skip_patterns`, so a produce run can protect the units the model's own serve recipe protects.** `streaming_w8a8_cast` has taken the module-path skip regexes since gw#557; the SNAPSHOT entry point the `cast-dtype` invoke actually calls did not forward them, so every produced `#fp8-w8a8` artifact was locked to the architecture-agnostic default set. Measured, headers only, $0: on MiniMax-H3's real DiT manifest that default selects **362 units / 66.09 GB** against the serve recipe's **300 / 38.54 GB** — a strict superset whose extra 62 units are the 12 `token_refiner` linears (fine, +1.53 GB of coverage) and **all 50 `transformer_blocks.*.adaln_proj.linear` weights (26.01 GB, 39% of the DiT)**. The default knows `adaln_single` and not `adaln_proj`, and those 50 are exactly the modulation stack the serve recipe keeps bf16 and te#171's AdaLN-skip precompute consumes as bf16. Model-specific selection is INVOKE data — the `weight_set_patterns` precedent — so the fix is the parameter, never a name added to the shared default, which would silently change what every other family's produce run emits. RED-proven (`TypeError` before the parameter) with the real producer over real safetensors, no mocks.
