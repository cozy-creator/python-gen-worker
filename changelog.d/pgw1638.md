- **pgw#1638: `ctx.load` runs the config's quantizer over the meta skeleton, so fp8-blockwise checkpoints load again.** The skeleton was built with the bare `cls(config)`, and `HfQuantizer.preprocess_model` — the step that swaps `nn.Linear` → `FP8Linear` and registers `weight_scale_inv` — lives only inside `from_pretrained`. So a component whose config declares a quantization came up as plain linears with no home for a single scale tensor: `minimax-h3` 0.12.8 died on an H200, three identical attempts, `357 tensor(s) name nothing in component 'text_encoder'` — 51 layers × 7 quantized linears, every orphan a `weight_scale_inv`, against a checkpoint that was correct. Same family as pgw#1626 (`tie_weights()`, also skipped, also paid for on a pod), so the preparation `from_pretrained` runs is now written out in `skeleton.py` in its order, with the trailing `postprocess_model` as `skeleton.finish_quantized()` after the stream. The declared contract is cross-checked against the image's decode set before anything is swapped, a quantization method that names no tensor-layout contract is refused by name, and a diffusers component declaring one is refused rather than silently mis-built.
