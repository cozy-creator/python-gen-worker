- **pgw#1284 (th#2006's SDK half): a ref may name WHICH variant of a release it
  means, and the spec rides BESIDE the address.** The grammar gains the
  `?<lane-spec>` tail — `owner/repo@prod?quant=plain.bf16@1`, the compact
  contract pattern the hub's config record already reads. 0.117.0 RAISED on it
  (`_parse_tensorhub_ref` split the `@` tail first, and the `@1` inside a quant
  handle tripped the separator rule), so a spec-carrying ref reached a rented
  pod as a `ValueError`. It is now cut AFTER the fragment split — a `?` on the
  FRAGMENT half is still the lockfile-attribution query both parsers discard —
  and carried in `TensorhubRef.lane_spec`.

  **`canonical()` DROPS it, deliberately.** The spec is a resolution input, not
  an address: `canonical()` is what mints wire refs, residency keys and cache
  keys, and a spec there is an unread copy of a decision the hub already made.
  Go's `CanonicalRef.String()` keeps the tail and `CanonicalRef.Address()` drops
  it — Python's `canonical()` is the twin of `Address().String()`, and the
  shared corpus now names both forms (`canonical` and `address`) rather than
  leaving one side to infer the other. Every fold lands on the address, so no
  pgw path can mint the `owner/repo@prod@sha256:…?quant=…` double-`@` th#2006
  found on the hub side. An empty `?` is refused by name.

- **pgw#1284: `ModelRef.label` is injective again (ie#727 residue).** The fold
  appended the release only when the label carried no `@` at all, which dropped
  it twice: off a civitai ref that also pinned a `version=`, and off a hub ref
  whose `path` already carried a release the side-channel `release=` OVERRIDES.
  The second case made `label` and `wire_ref` name different artifacts, so
  `model_used` reported the ref that was not fetched. The hub branch is now the
  same fold the wire uses, and a huggingface/modelscope `revision=` reaches the
  label at all — it only ever reached it through `release`, which those sources
  never set. `release=` on a non-tensorhub binding is REFUSED rather than
  silently dropped: it is the tensorhub axis, nothing else fetches by it.
