- **`@job(emits_media=True)` — the media sibling of `publishes=`.** A job that writes a report, a
  contact sheet or a sample grid now DECLARES it, and the hub mints its `upload_media` grant off
  that declaration (th#2069). Undeclared media reaching `save_bytes`/`save_file` is a typed
  `MediaNotDeclaredError` at the call site instead of a 403 after the bytes moved, and the flag is
  stamped from the `JobSpec` by `execute_job` so a dispatch head cannot forget it — the same one-home
  shape `publishes` uses, including the refusal when a caller claims authority the release never
  declared. It is independent of `publishes`: an eval job declares `emits_media=True, publishes=False`.
  Endpoints declare nothing, because media IS an endpoint's product.

- **An unknown local-context `kind` refuses instead of silently getting a base `RequestContext`.**
  `build_local_context` handed a typo'd or unported kind the base class, which lacks the surface the
  kind implies — so the substitution surfaced as a missing attribute deep inside a tenant body rather
  than at the factory. The kind vocabulary has one home (`api.decorators.KINDS` plus `job`).

- **The `compute_capability` back-projection is deleted from the manifest.** `Resources.manifest_dict`
  emitted the dotted key beside `requires` for the window before the hub read the requirement row.
  th#2072 closed that window: the hub prefers `requires` wherever present, and this method emitted the
  projection only when `min_sm` was declared — i.e. only when `requires` already answered — so the arm
  was unreachable for any wheel built from this source. A machine requirement now rides ONE key.
